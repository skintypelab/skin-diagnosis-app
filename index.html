FAQ

よくある質問

サービスへの疑問にお答えします。

ランキングや比較サイトですか？▼
いいえ、違います。SKIN TYPE LAB はランキングサイトでも比較サイトでもありません。「どのブランドが優れているか」ではなく「どの商品があなたの肌に合うか」をご提案することが目的です。掲載ブランドに優劣はなく、あなたの診断結果に基づき中立的に商品をご提案します。
個人情報は保存されますか？▼
いいえ。このサービスはサーバーへの情報送信を一切行いません。診断データはお使いのブラウザ内だけで処理され、外部サーバーに送信・保存されることはありません。登録・ログインも不要です。安心してお使いください。
このサービスは何ですか？▼
13の質問に答えるだけで、あなたの肌タイプ（乾燥肌・脂性肌・敏感肌など）を診断し、肌悩みに合った韓国コスメ・日本ブランドのスキンケアをご提案するマッチングサービスです。全145商品から肌タイプ・悩み・成分・カテゴリーでフィルターして探すこともできます。
商品はどのように選ばれていますか？▼
成分の有効性・使用感・口コミ評価をもとに、肌タイプ別に厳選しています。掲載商品はすべて日本国内で正規販売されている商品です。アフィリエイト報酬は商品の選定基準に一切影響しません。
購入リンクはアフィリエイトですか？▼
AmazonおよびQoo10へのリンクにはアフィリエイトリンクが含まれる場合があります。リンクを経由してご購入いただくと、運営者に紹介料が支払われることがありますが、商品の選定・評価への影響は一切ありません。
診断結果はどのくらい正確ですか？▼
入力いただいた情報をもとに、皮膚科学の知見に基づいてお肌のタイプを推定しています。医療診断ではなく参考情報です。肌の状態は季節・体調・生活習慣によって変化するため、変化を感じたら再診断をお試しください。
何度でも診断できますか？▼
はい、何度でも無料でお試しいただけます。季節の変わり目や肌の変化を感じたときに再診断するのがおすすめです。商品ページの「最初から診断する」ボタンからいつでも再スタートできます。
韓国コスメと日本コスメ、どちらが合いますか？▼
「どちらが優れているか」ではなく「どちらがあなたに合うか」が重要です。韓国コスメはトレンドを取り入れた成分配合と手頃な価格が魅力。日本コスメは厳格な品質管理と安定した使用感が強みです。SKIN TYPE LAB ではどちらも公平にご提案し、あなたの肌に合う商品をご紹介します。
成分チップとは何ですか？▼
商品カードに表示されるカラーのタグが「成分チップ」です。タップすると、その成分の効果・注意点・同じ成分を使用している商品一覧を確認できます。成分を知ることで、より自分の肌に合った商品選びができます。
乾燥肌でもニキビはできますか？▼
はい、できます。乾燥肌は皮膚バリアが弱まりやすく、外部刺激や細菌が侵入しやすい状態です。また、乾燥を補おうと皮脂が過剰分泌されることで毛穴が詰まりニキビにつながる場合もあります。保湿を徹底しながら、ノンコメドジェニック処方のスキンケアを選ぶことが大切です。
ニキビ肌でも保湿は必要ですか？▼
はい、必要です。保湿不足は皮脂の過剰分泌を招き、かえってニキビを悪化させる場合があります。オイルフリーのジェルや水性クリームなど、軽いテクスチャーの保湿アイテムを選びましょう。ヒアルロン酸やセンテラアジアチカ配合のスキンケアアイテムは、ニキビ肌にも使いやすく効果的です。

💡 SKIN TYPE LABを作った理由
「乾燥肌なのにニキビができる」「何を使えばいいかわからない」――こうした悩みをもつ方が多くいることに気づいたのが始まりです。

SNSのスキンケア情報は断片的で、誰に向けたものかが不明確なことが多いと感じていました。皮膚科に行くほどではないけれど、自分の肌に合ったスキンケアを知りたい。そのニーズに応えるため、13問の質問から肌タイプと悩みを診断し、成分ベースで商品を提案するサイトを作りました。

医療的な診断を行うサービスではありませんが、「なぜこの商品が自分に合うのか」を成分から理解できる設計にしています。
🔬 診断ロジックについて

13問の質問への回答をもとに、以下の10カテゴリを独自スコアリングで評価します。

  • 乾燥（dry）：洗顔後のつっぱり・乾燥しやすさ
  • インナードライ（innerDry）：外は脂っぽいが内側は水分不足
  • 脂性（oily）：テカリ・皮脂量
  • 混合肌（combo）：Tゾーンのみテカリ・季節変化
  • 敏感肌（sensitive）：赤み・炎症・外部刺激への反応
  • 普通肌（normal）：悩みが少なく安定している
  • ニキビ（acne）：吹き出物・肌荒れの頻度
  • 毛穴（pore）：開き・黒ずみ・たるみ毛穴
  • 美白（brightening）：シミ・くすみ・そばかす
  • エイジング（aging）：ハリ低下・シワ・たるみ

最も高いスコアの組み合わせから「肌タイプ」を判定し、次点以降のスコアから「悩み」を特定して商品を提案します。

※ このロジックは一般的な皮膚科学の知見をもとに作成したものであり、医療診断ではありません。肌に異常を感じた場合は皮膚科医にご相談ください。

🌿 おすすめ商品の選定基準

商品は以下の基準をもとに選定しています。アフィリエイト報酬の有無は選定に影響しません。

  • 肌タイプへの適合性：診断結果のスコアと成分の相性を優先
  • 主要成分の有効性：ヒアルロン酸・ナイアシンアミド・セラミド・レチノールなど、有効性に関する研究報告のある成分を重視
  • 処方の透明性：全成分表示（INCI）が公開されている商品を対象
  • 継続しやすい価格帯：日常使いできるコストパフォーマンス
  • 市場での実績：複数の販売プラットフォームで一定の評価があるもの
  • 中立性：特定ブランドとの広告契約はなく、成分と肌タイプの適合性のみで選定

20代から乾燥肌・インナードライに悩み、数十種類のスキンケアを試してきました。その経験から「成分を知れば、商品選びの軸ができる」という確信に至り、成分チップ機能やタイプ別フィルターに反映しています。

スキンケアに正解はなく、肌の状態は季節・生活習慣・年齢によって変化します。このサイトはその変化に寄り添い、何度でも診断しなおせる設計にしています。

SKIN TYPE LAB サイト運営について
🧪 SKIN TYPE LABとは

SKIN TYPE LAB は、13問の肌診断であなたの肌タイプを分析し、乾燥肌・混合肌・敏感肌・ニキビ肌など10タイプそれぞれに合ったスキンケア商品を提案する、無料の肌診断Webアプリです。

韓国コスメ・日本コスメを横断的に比較できる点と、ランキングや広告順位に左右されない「肌タイプへのマッチング」による提案が特長です。登録不要・約2分で診断が完了します。

🎯 サイト運営目的

「スキンケア選びで失敗したくない」「自分の肌に本当に合うものが知りたい」という方のために、専門知識がなくても肌タイプを把握し、適切なスキンケアを選べる場を提供することを目的としています。

医療機関への受診を促すことを目的としたサイトではなく、日常的なスキンケア選びをサポートする情報提供サービスです。診断結果は参考情報であり、皮膚科医による診断を代替するものではありません。

🌿 商品の選定方針
  • 肌タイプへの適合性（成分・処方）を最優先に選定
  • ランキング・売上データ・広告出稿の有無は選定基準に含めない
  • アフィリエイト報酬の有無に関わらず、掲載商品の評価基準は同一
  • 日本国内で正規販売されている商品を対象とする
  • 敏感肌・ニキビ肌向けは低刺激・処方面を特に重視
  • 情報は定期的に見直し、古い情報は更新または削除する
